TROUBLESHOOTING:
----------------
If images still don't upload:

1. Check flash messages for errors
2. Verify file type is image/* or video/*
3. Check PHP upload_max_filesize in php.ini
4. Check post_max_size in php.ini
5. Verify directory exists and is writable:
   ls -la public/uploads/events/
